# Data

This folder holds the input data for the Hakai BioMarathon CO1 eDNA dataset, plus the intermediate files produced by the scripts in [`code/`](../code). The final Darwin Core tables submitted to OBIS are in [`obis/`](../obis).

All samples were collected at Hyacinthe Bay, Quadra Island, British Columbia (site QU38).

## Input data

| File | Contents |
|---|---|
| `Biomarathon_ASV_table_MarineInverts.csv` | ASV read counts: one row per ASV (1,832 ASVs, marine invertebrates) and one column per sample (463 columns). Columns include seawater samples and field blanks (`QU38xxxx`), extraction blanks (`bio1-`/`bio2-QU38XN...`) and PCR blanks (`NEG-PCR1`–`6`). |
| `Biomarathon_taxonomy_file.csv` | Classifier output for all 3,278 ASVs: lowest-common-ancestor rank and taxon (`#lca rank`, `#lca taxon`), the lineage from kingdom to species, and the assignment method. Covers more ASVs than the ASV table, including non-invertebrate taxa. |
| `CO1.biomarathon_combined.ASV_sequences.fasta` | CO1 DNA sequence of each ASV (12,641 sequences). |
| `Lab Metadata Template - Aquatic.xlsx` | Sample metadata in three sheets: **field sheet** (collection date, site, coordinates, depth, volume filtered, sample type), **lab sheet** (extraction and sequencing details, and the extraction and PCR blank linked to each sample) and **batch sheet** (sequencing-run settings such as primers, target gene and platform). `sample_type` identifies seawater samples and field, extraction and PCR blanks. |
| `Biomarathon_eDNA_metadata.csv` | Original sample sheet from the lab (477 samples): project, sample type, library, collection and extraction dates, tide, depth, volume and staff notes. Kept for reference; the scripts use the Excel template instead. |

## Files generated by the scripts

| File | Created by | Contents |
|---|---|---|
| `Hakai_BioMarathon_taxonomy_COI_worms.csv` | `01_worms_taxonomic_cleaning.R` | Cleaned taxonomy for each ASV in the ASV table, matched to WoRMS: lineage, `scientificName`, `scientificNameID` (AphiaID), `taxonRank`, `scientificNameAuthorship`, plus `verbatimIdentification`, `identificationQualifier`, `identificationRemarks` and `taxonConceptID` (BOLD BIN). Script 02 uses this table. |
| `Biomarathon_ASV_table_obis_comparison.csv` | `02_dwc_standardization.R` | One row per ASV in the ASV table, showing its original identification, the name it was submitted under and whether it is in the OBIS occurrence core (`includedInOBIS`). ASVs not included have reads only in blank samples, or were excluded on purpose (`excluded_asvs` in script 02). |
